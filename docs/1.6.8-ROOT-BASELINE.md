# 晓晓呀 KTV v1.6.8 根版本基线

> 本文档是项目后续开发、维护、测试和发布的最高优先级基线约定。

## 根版本定义

- 产品：晓晓呀 KTV
- 根版本：**v1.6.8 正式版**
- 根源码基线提交（QA 基线）：`bcd42c8a32d7adcf7642041db8b90805b4b0cff8`
- 私有仓库：`redhatlxg/xiaoxiao-ktv`
- 私有稳定分支：`stable/1.6.8`
- 公共总仓库：`redhatlxg/xiaoxiao-ktv-1`
- 正式 APK 归档：私有仓库 `private-backups/installers/v1.6.8/`
- 正式下载发布：`https://github.com/redhatlxg/xiaoxiao-ktv-download/releases/tag/v1.6.8`

## 不可违反的开发规则

1. v1.6.8 是项目永久保留的原始根基线。后续功能、修复、重构和界面调整，均以该版本的源码状态为共同起点。
2. 根版本只读保护：不得直接在根版本标签、根版本归档或 `stable/1.6.8` 上开发，不得移动或覆盖 v1.6.8 标签，不得用新代码覆盖 v1.6.8 正式 APK。
3. 每项新工作从 v1.6.8 根基线创建独立开发分支，建议命名为 `feature/<功能名>` 或 `fix/<问题名>`。若后续已有明确的新开发主线，必须能追溯到该根基线，并保留完整提交历史。
4. 新功能先独立实现、构建和测试；通过审查后再合入后续开发版本。不得未经验证直接替换稳定版本。
5. 每个正式版本使用新的版本号和 versionCode，单独生成正式签名 APK、SHA-256 校验文件和发布记录。
6. 每次发布都保留源码提交、构建记录、测试结果、签名证书指纹、APK 和校验文件，确保可以定位和回退。
7. 如果新版本出现严重问题，优先回退到最近一个通过验证的正式版本；必要时可直接从 v1.6.8 根基线重新开分支。
8. 正式签名密钥、密码和令牌只保存在受控安全环境，不得写入仓库、文档或提交记录。

## 仓库职责

- 私有仓库用于受控开发、稳定基线、正式签名和私有备份。
- 公共总仓库用于公开源码与项目说明；同步时只同步经过确认的源码和文档，不得公开签名密钥、凭据或私有安装包备份。
- 下载仓库用于对外发布正式安装包及其校验文件。
- `private-backups` 用于保存私有归档，不作为日常功能开发分支。

## 正式版发布检查

- [ ] 确认本次变更可追溯到 v1.6.8 根基线。
- [ ] 确认新版本号、versionCode 均未使用过。
- [ ] QA 工作流成功，关键自动化检查通过。
- [ ] 在目标电视/盒子上完成安装与关键流程实测。
- [ ] 使用正式签名密钥构建并验证 APK 签名。
- [ ] 生成 SHA-256 校验文件并复核。
- [ ] 更新版本记录、构建发布手册和 Release 说明。
- [ ] 将正式 APK 与校验文件归档到私有备份，并发布对应正式 Release。
