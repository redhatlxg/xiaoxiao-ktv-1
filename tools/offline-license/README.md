# 晓晓呀 KTV 1.6.9 离线短激活码

## 方案

- 仅使用安卓手机《晓晓呀 KTV 手机离线授权助手》签发短激活码。
- 不再支持旧 RSA 长授权码，不再保留 Windows/电脑注册机。
- 不需要授权服务器、Cloudflare、数据库、登录或联网。
- 电视端显示 12 位机器码，样式为 `XX:XX:XX:XX:XX:XX`。
- 手机端支持 7、30、90、365 天、永久和自定义 1–65535 天；0 表示永久。
- 限时授权从电视第一次成功激活时开始计时。
- 电视主界面右上角显示免费试用或授权剩余时间；到期后阻止继续使用并提示激活。

## 短码格式

短激活码为 10 字节，显示为十组十六进制字节：

`TT:TT:NN:NN:HH:HH:HH:HH:HH:HH`

前 2 字节为期限天数（`0000` 表示永久），再 2 字节是随机数，末尾 6 字节是 HMAC-SHA256 截断校验值。校验值绑定电视机器码。

## 使用流程

1. 在电视授权窗口复制机器码。
2. 在安卓手机打开《晓晓呀 KTV 手机离线授权助手》。
3. 输入机器码，选择预设期限或输入自定义天数。
4. 点击“生成激活码”，复制短码。
5. 回到电视粘贴并激活。

## 安全边界

为了做到完全离线和短激活码，手机与电视 APK 中必须包含同一对称校验密钥。当前激活码使用 48 位截断 HMAC，设备绑定可防止普通跨设备使用和手工改码，但有能力的逆向分析者仍可能从 APK 中提取密钥；安全强度低于 RSA 等公钥签名方案。离线签发也无法远程撤销已生成的授权码。请妥善保管授权手机。
